# Database migrations

The source of truth is the EF Core migrations in
`src/SupermarketBilling.Infrastructure/Persistence/Migrations`.

`supermarketbilling.sql` is an **idempotent** SQL export of all migrations, regenerated by
`scripts/db-migrate.ps1`. Use it for offline installation or review by a DBA. Apply it as the migrator
(schema-owner) account, never as the runtime account:

```powershell
Get-Content database\migrations\supermarketbilling.sql -Raw |
  docker exec -i supermarketbilling-db psql -v ON_ERROR_STOP=1 -U sb_migrator -d supermarketbilling -f -
```
